# DROID FURY

Shooter arcade top-down neón. Sobreviví oleadas de androides, comprá armas y chips, encadená combos y derribá jefes.

## Jugar local

```
npm start
```

Abrí http://localhost:3000

## Deploy en Railway

Servidor Node estático sin dependencias (`server.js`). Railway detecta `package.json` y ejecuta `npm start`, escuchando en `$PORT`.
